Privacy, by permission.

Effective date: October 19, 2026

What this application does

This is a personal automation tool that uses Google OAuth to work with the account owner’s own data. It may request access to Gmail, Google Analytics, Search Console, Site Verification, and Indexing data only after the user reviews and explicitly approves Google’s authorization screen.

How data is used

Authorized data is used only for the personal automation task requested by the user. The application does not use the data for advertising, profiling, resale, or unrelated purposes.

Collection, storage, and sharing

  • The application does not collect personal data for a separate service.
  • The application does not store Google data as a hosted service.
  • The application does not share Google data with third parties.

Revoking access

You can revoke authorization at any time from your Google Account’s connected-app permissions. After authorization is revoked, the application can no longer access the affected Google services unless you explicitly authorize it again.

Changes to this policy

If this policy changes, the updated effective date will be shown on this page.
